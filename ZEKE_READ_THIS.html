Hello Zeke, so this is where you are able to edit your website. Some notes for you: 1. If you want to upload something to the website, lets say a settings page. In order to do that you need to click "Add File" (or that + button), select Create new file, and then if you want the page link to be something like https://join365.pages.dev/Settings you have to name the page Settings/index.html , which will make a Settings folder. If you just name it Settings.html then the link will be https://join365.pages.dev/Settings.html which doesn't look very nice. 2. If you want to edit the Not Found page (the page that shows up when a user goes to a non-existent page on your website, for example: https://join365.pages.dev/hguwrhuigrjh ) you need to edit the 404.html file, which i already made for you. 3. Unfortunally, you cannot get DNS with a subdomain (Subdomains are websites like example.example.com , and join365.pages.dev is a subdomain). But really, you aren't missing out on a lot of stuff. 4. DO NOT delete the CNAME file, that is the file that tells Cloudflare that you own join365.pages.dev , if you delete it, your website will not work on join365.pages.dev 5. The index.html is the main page of your website, you can edit it however you want. But if you delete it, then when a user goes to https://join365.pages.dev they will get the 404 Page Not Found.
