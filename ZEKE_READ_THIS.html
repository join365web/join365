Hello Zeke, so this is where you are able to edit your website. Some notes for you: 1. If you want to upload something to the website, lets say a settings page. In order to do that you need to click "Add File" (or that + button), select Create new file, and then if you want the page link to be something like https://join365.mytunnel.org/Settings you have to name the page Settings/index.html , which will make a Settings folder. If you just name it Settings.html then the link will be https://join365.mytunnel.org/Settings.html which doesn't look very nice. 2. If you want to edit the Not Found page (the page that shows up when a user goes to a non-existent page on your website, for example: https://join365.mytunnel.org/hguwrhuigrjh ) you need to edit the 404.html file, which i already made for you. 3. Fortunaly, Dynu supports DNS, so you can use DNS when needed for stuff like Firebase custom email, or to make something like a gmail on your website. https://dynu.com 4. DO NOT delete the CNAME file, that is the file that tells Dynu that you own join365.mytunnel.org , if you delete it, your website will not work on join365.mytunnel.org 5. The index.html is the main page of your website, you can edit it however you want. But if you delete it, then when a user goes to https://join365.mytunnel.org they will get the 404 Page Not Found. 6. When you add a file, edit HTML, upload a file, rename a file, or do anything like that, it takes about 20 to 30 seconds for the updates to save, for example when you edit the index.html, it will take 30 seconds for it to actually upload the changes to the website.
